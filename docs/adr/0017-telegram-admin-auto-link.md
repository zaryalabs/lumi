# ADR 0017: Автопривязка Telegram-бота к администратору

Status: accepted

## Контекст

Встроенного Telegram-бота может добавить или заменить только администратор
экземпляра Lumi. Дополнительный одноразовый pairing token заставлял того же
администратора после настройки бота возвращаться в личные подключения, создавать
код и отправлять `/start <token>`, хотя владелец назначения уже известен серверу.

## Решение

- При сохранении BotFather token Lumi запоминает `user_id` и `device_id`
  администратора, который настроил бота.
- Первое валидное сообщение в private chat атомарно создаёт
  `TelegramIdentity` для этого администратора. Само сообщение сразу проходит в
  обычный import pipeline; предварительный `/start` не обязателен.
- `/start` без параметров остаётся справочной командой и подтверждает готовность
  бота. `/start <token>`, pairing API и пользовательский одноразовый код
  удаляются.
- Один бот по-прежнему допускает одну активную Telegram identity. Сообщения из
  другого private chat не импортируются.
- BotFather token по-прежнему проверяется через `getMe`, хранится зашифрованным
  и никогда не возвращается клиенту.
- Отключение выполняется администратором через удаление глобальной настройки
  бота. Отдельный `/unlink` больше не нужен.

## Последствия

После добавления бота администратор может сразу отправить или переслать материал.
Автопривязка защищена PostgreSQL advisory lock и существующими уникальными
ограничениями `telegram_identities`, поэтому параллельные первые updates не
создают несколько владельцев.

Миграция сохраняет `configured_by_device_id` и восстанавливает его для старой
настройки через последний активный device администратора. Таблица
`telegram_pairing_tokens` остаётся в legacy schema для совместимого обновления,
но активный код её больше не читает и не заполняет.

## Compatibility

- Существующая активная `TelegramIdentity` продолжает работать.
- Старый сохранённый бот получает owner device во время миграции, если у
  администратора есть активный device.
- Клиенты должны использовать capability `telegram-admin-auto-link` вместо
  `telegram-one-time-pairing`.
