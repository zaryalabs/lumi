# Отчет Stage 0 для Lumi `0.2.0`

Status: `completed`

Дата: 2026-07-25

## Назначение

Отчет фиксирует воспроизводимые risk probes перед Contract Freeze 1. Spike-код
изолирован в `spikes/` и не является production architecture. Durable решения
перенесены в ADR 0019–0024 и canonical `docs/systems/`.

Decision labels:

- `adopt` — граница пригодна без архитектурной замены;
- `adapt` — пригодна только через явно описанный adapter/ограничение;
- `reject` — вариант не проходит gate и заменяется.

## Итог

| Spike | Решение | Подтверждено | Обязательное ограничение |
| --- | --- | --- | --- |
| Deep Chat 2.5.0 | `adapt` | Web Component загружается без второго UI runtime; public handler поддерживает streaming и stop; history восстанавливается после reload; composer focusable; mobile viewport не переполняется | Dioxus владеет history/generation/attachments/citations; Lumi-specific controls не зависят от Shadow DOM; Dioxus-native fallback сохраняется |
| OpenRouter-compatible adapter | `adopt` | local Axum mock проверяет SSE comments/deltas/`[DONE]`, strict structured payload, timeout cancellation, 429 mapping, mid-stream error и output limit | adapter нормализует provider events/errors; endpoint не задается account; CI не использует live key/provider |
| MCP transport/auth | `adopt` | stateless Streamable HTTP `POST /mcp`, initialize/tools call, Bearer auth, account binding и immediate revocation работают без session state | protocol `2025-06-18`; auth на каждом request; tool schemas/fencing versioned snapshots |
| Explicit source context | `adopt` | normalized reflowable/fixed-layout records дают bounded EPUB, Markdown и PDF fragments с source citations; stale revision и cross-account actor отклоняются | exact revision, repeated permission check, 256 KiB hard pack limit, no ranking/search |
| Hierarchical summary | `adapt` | fixture из 96 sections редуцируется bounded batches по 8 input units через два synthesis levels, сохраняя citation coverage | intermediate summaries — Job data; coverage check обязателен; одна большая книга не отправляется одним provider request |
| Generated `.lum` | `adopt` | generated two-chapter package с reserved provenance повторно импортируется существующим strict `.lum` pipeline и сохраняет LUM source locators | authoritative relation в PostgreSQL; portable metadata в `META-INF/lumi/provenance.json`; atomic publication после ordinary validation/import |

Gate Stage 0 пройден: после принятых ограничений нет открытого вопроса,
который меняет AI schema, security boundary или публичный HTTP/MCP API.

## Evidence и команды

### Rust probes

Реализация:

- `spikes/stage0/src/openrouter.rs`;
- `spikes/stage0/src/mcp.rs`;
- `spikes/stage0/src/explicit_context.rs`;
- `spikes/stage0/src/hierarchical_summary.rs`;
- `spikes/stage0/src/generated_lum.rs`.

Команда:

```sh
cargo test -p lumi-stage0-spikes
```

Probe использует только local/in-process fixtures. OpenRouter wire choices
сверены с официальными описаниями
[streaming](https://openrouter.ai/docs/api/reference/streaming),
[structured outputs](https://openrouter.ai/docs/guides/features/structured-outputs)
и [errors](https://openrouter.ai/docs/api/reference/errors-and-debugging).

### Deep Chat browser probe

Изолированная поверхность и pinned dependency:

- `spikes/ai-web/`;
- `tests/e2e/ai-stage0-spike.spec.ts`;
- `tests/e2e/ai-stage0-spike.playwright.config.ts`.

Команда:

```sh
make ai-chat-spike-e2e
```

Chromium gates проверяют server-state adapter flow, streamed response, stop,
reload и selection attachment. Mobile Chromium отдельно проверяет focus и
viewport. Используются public
[handler/signals](https://deepchat.dev/docs/connect/) и
[events](https://deepchat.dev/docs/events/); внутренние message/attachment
форматы не переходят в Lumi contracts.

## Exact release scope

Canonical release profile находится в
[`../systems/ai.md`](../systems/ai.md#release-profile-020). Он поставляет
BYOK OpenRouter, global chat, explicit context, durable task/artifact/summary
flows, MCP worker/product slice и derived `.lum`.

За границей остаются subscription/billing/hosted Lumi key, additional
providers, local/native execution, voice/learning generators, indexed/global
retrieval, agent UI in chat, per-tool MCP grants и автоматическая regeneration.

## Threat review

Canonical review:
[`../systems/ai-threat-review.md`](../systems/ai-threat-review.md).

Review закрывает обязательные threat classes:

- secret exfiltration;
- prompt injection;
- cross-account context leak;
- stale MCP claim;
- SSRF/provider endpoint;
- oversized context/output/result/package;
- log leakage.

Дополнительно зафиксированы malicious structured output, derived package
injection, replay/idempotency, resource exhaustion и citation spoofing.

поля. Breaking shape создается в новом version directory и требует обновления
ADR/consumers.

## Остаточные implementation gates

Это не открытые архитектурные решения:

- проверить Deep Chat внутри реального Dioxus shell и reconnect к production
  conversation API;
- реализовать provider mock с socket disconnect/first-token delay в server
  contract tests;
- прогнать PostgreSQL concurrency matrices на migrations этапов A1/B2/C1;
- подтвердить production rate/concurrency values нагрузочными измерениями;
- выполнить security plaintext scans и backup/restore drill на hardening.
