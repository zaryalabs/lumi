# Contract Freeze 1 — отчет

Дата: 2026-07-25  
Статус: `passed`

## Результат

Минимальная общая поверхность `0.2.0` опубликована и проверяется executable
contract tests. Последовательные пакеты A, B и C собираются против одних DTO,
version ids, provider events, mock services и MCP fencing.

Порядок исполнения после freeze задаёт
[`ROADMAP.md`](ROADMAP.md); прежняя модель независимого запуска пакетов
отменена.

## Core contracts

Добавлены `crates/lumi-core/src/ai.rs` и `mcp.rs`:

- ids для task, run, context pack, artifact, conversation, message, generation,
  claim и MCP connection;
- `AiTaskStatus`, `AiRunStatus`, `AiArtifactStatus`,
  `AiGenerationStatus` и допустимые transitions;
- task/run/chat/artifact projections и create/mutation commands;
- revision-bound `AiSourceScope`, bounded `AiContextPack`,
  `AiContextFragment`, `SourceCitation` и typed source locators;
- provider descriptors, write-only credential request с redacted `Debug` и
  zeroize-on-drop, provider-neutral requests/events/errors;
- prompt registry из четырех summary variants;
- strict `summary-artifact.v1` output schema и validator;
- MCP connection DTO, tool allowlist, claim/fence/progress/fail/complete
  contracts и limits.

Domain marker повышен с `s1.2026-07-23.lum-import-v1` до
`s1.2026-07-25.ai-contract-v1`; migration catalog содержит
`s1-0011-ai-contract-freeze-v1`.

## HTTP и MCP snapshots

`tests/fixtures/ai/contracts/v1/` теперь содержит:

- Rust-compatible task/context/provider-event/summary snapshots;
- `schema-registry.json`;
- `http-routes.json` для providers, chat, tasks, summaries, artifacts и MCP
  connection management.

`tests/fixtures/mcp/contracts/v1/` содержит:

- Streamable HTTP initialize/tool snapshot;
- полный `0.2.0` tool allowlist с input/output schema version ids;
- обязательные claim result и mutation fencing fields;
- claim/complete examples, которые напрямую загружают core tests.

Breaking change создает новый version directory/id. Изменение `v1` на месте
запрещено и требует отдельного contract change с согласованием A, B и C.

## Shared mocks

`lumi-server::ai` публикует:

- `AiProviderClient` с normalized event stream и structured completion;
- deterministic FIFO `MockAiProvider`;
- `AiTaskApplicationService`;
- `MockAiTaskService` с account scope, active dedupe, atomic mock claim,
  monotonic fence, stale completion rejection и idempotent completion replay.

Mocks не включают production capabilities и не заменяют persistence/race tests
этапов A1–A4.

## Router composition и ownership

Existing `/api/v1` composition вынесена из `lib.rs` в `api_routes.rs`.
Подключены отдельные contributions:

- `ai::routes` и `ai::chat`;
- `mcp::management_routes`;
- top-level `mcp::transport_routes`.

До реализации соответствующих пакетов новые routers пусты, поэтому capability
правило не нарушено.

Ownership закреплен в
[`../systems/ai-contracts.md`](../systems/ai-contracts.md):

- A — core AI contracts и platform modules;
- B — conversation module/migration и Web AI surface;
- C — MCP modules/migration и derived content;
- назначенный maintainer точки Sync/Release — integration owner для workspace
  `Cargo.toml`, `lib.rs`, `api_routes.rs`, capabilities и top-level Web
  navigation.

## Проверки

Выполнены:

- `cargo test -p lumi-core -p lumi-server --lib --offline`;
- `make l`;
- `make c`;
- JSON parse всех AI/MCP contract fixtures;
- `git diff --check`.

Contract tests проверяют state transitions, version registries, snapshot/Rust
catalog parity, context/artifact validation, MCP tool allowlist, обязательные
fencing fields, mock stream ordering, task dedupe и stale completion.

## Gate

Gate пройден:

- core contract tests и committed fixtures проходят;
- shared mock provider/task service доступны всем пакетам;
- route/module ownership и integration owner определены;
- дальнейшее breaking изменение frozen contract оформляется отдельным
  contract change с обновлением всех затронутых пакетов и fixtures.
