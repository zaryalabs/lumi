# Lumi 0.4.0

Status: released repository-side

## Что вошло

- Annotation v2, rich highlights, margin/voice notes и portable export;
- stable links, wikilinks и backlinks;
- rebuildable Desk projection;
- BM25 + verified fastText search, retrieval и MCP parity;
- record-scoped RAG через существующий global chat с видимым context,
  проверяемыми citations и entry points из Reader, Desk и Search.

## Известные ограничения

- нужен пользовательский OpenRouter BYOK; hosted AI отсутствует;
- query отключается при недоступной/непроверенной fastText model, без
  BM25-only fallback;
- RAG использует только индексируемые active personal records и максимум
  16 chunks/64 KiB на сообщение;
- audio без принятого transcript не участвует в text retrieval;
- external staging/TLS/DNS/operator acceptance зависит от окружения.

## Обновление

Развернуть additive-compatible server, применить migrations, выполнить Desk и
Search rebuild. Из-за `tantivy.v2` старый derived index нельзя переиспользовать.
Подробности: [`record-rag.md`](../runbooks/record-rag.md) и
[`search-index.md`](../runbooks/search-index.md).

## Rollback

Primary records и chat state не откатывать и не удалять. Вернуть предыдущую
binary, удалить только несовместимый derived search directory и перестроить
поддерживаемую версию index. Новые JSON fields additive и старые source
attachments остаются читаемыми.
